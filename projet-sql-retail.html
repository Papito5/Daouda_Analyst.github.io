Analyse du Comportement Client (Retail) — de Python à Power BI

Projet bout-en-bout pour un leader du retail : préparation des données en Python, analyses avancées en SQL, et tableau de bord Power BI pour piloter ventes, satisfaction et fidélité.

Période : 2025 Outils : Python, SQL, Power BI DB : PostgreSQL / MySQL / MSSQL Libs : Pandas, SQLAlchemy, psycopg

Contexte et Objectif du Projet

Ce projet a été initié pour répondre au problématique stratégique d'entreprise de retail : mieux comprendre les habitudes d'achat de ses clients afin d'améliorer les ventes, la satisfaction et la fidélité à long terme. L'objectif principal était de leverager les données clients pour identifier des tendances claires, optimiser l'engagement et affiner les stratégies marketing et produits. Le livrable final devait fournir une plateforme interactive et des recommandations exploitables.

Le jeu de données inclut démographie (âge, genre), info produits (article, catégorie), transactions (montant), promotions (rabais), et indicateurs de fidélité (achats précédents, fréquence).

Méthodologie et Outils Utilisés

1) Préparation & Ingénierie des Données (Python)

  • Valeurs manquantes : imputation des 37 valeurs nulles de review_rating par médiane par catégorie (évite le biais vs médiane globale).
  • Standardisation : renommage des colonnes en snake_case pour cohérence et usage SQL.
  • Features : age_group via pd.qcut (young adult, adult, middle-aged, senior) ; purchase_frequency_days (mapping hebdo/mensuel → jours).
  • Redondance : détection de doublon entre discount_applied et promo_code_used → suppression de la colonne redondante.

2) Analyse & Requêtes Avancées (SQL)

  • Techniques : sous-requêtes pour repérer les clients dépensant > moyenne même avec rabais ; Window Functions (ROW_NUMBER()) pour classer les 3 produits top par catégorie.
  • Segmentation & KPI : CTE + CASE WHEN pour New, Returning, Loyal ; % d’achats avec rabais par produit pour mesurer la dépendance promotionnelle.

3) Visualisation & Communication (Power BI)

  • Dashboard : cartes KPI (Nb clients, panier moyen, note moyenne), revenus/ventes par catégorie & groupe d’âge.
  • Exploration : slicers par Statut d’abonnement, Genre, Catégorie, Type d’expédition.

Compétences Démontrées

  • Rigueur analytique : imputation par catégorie ; règles métier claires pour la segmentation client (New, Returning, Loyal).
  • SQL avancé : Window Functions (ROW_NUMBER()), sous-requêtes, CTE ; multi-SGBD (PostgreSQL / MySQL / MSSQL).
  • Python data : nettoyage robuste, snake_case, features (qcut, mapping fréquence).
  • BI & dataviz : dashboard interactif et orienté KPI pour décision managériale.
  • Gestion E2E & comm’ : de la problématique aux livrables (rapport, présentation), publication GitHub.

Résultats Clés & Livrables

  • Valeur client : les young adults génèrent le revenu total le plus élevé (suivis des groupes d’âge moyen).
  • Expédition : l’option Express est associée à un panier moyen plus élevé → opportunité d’investir dans la livraison rapide.
  • Abonnements : la majorité des repeat buyers ne sont pas abonnés → proposition de valeur à renforcer.
  • Livrables : dashboard Power BI interactif, rapport projet détaillé, présentation synthétique.
