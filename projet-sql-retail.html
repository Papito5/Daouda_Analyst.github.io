Analyse de données avec SQL — Retail / Business Insights

Cas complet d’analyse SQL sur données de ventes : tendances, performances, part‑à‑tout, segmentation clients & produits, et livrables utiles aux décideurs.

Période : Mars 2025 Outils : SQL Techniques : JOIN, GROUP BY, Window Functions, CTE Dépôt : GitHub (à venir)

Objectif

Répondre à des questions business à partir d’un schéma de ventes : évolution (trend), performance (meilleurs produits/segments), part‑à‑tout par catégorie/canal et segmentation clients, puis produire des rapports clients/produits.

Jeu de données & schéma

Modélisation compréhensive du schéma (tables, clés, relations). Validation des clés étrangères et du sens métier des champs (dates, montants, identifiants).

  • Tables typiques : customers, orders, order_items, products, categories, regions.
  • Relations : orders.customer_id → customers.id, order_items.product_id → products.id, etc.

Méthodologie SQL

  • Jointures (INNER/LEFT) et agrégations (GROUP BY, SUM, COUNT).
  • Fenêtres : ROW_NUMBER, LAG/LEAD, cumul (SUM() OVER).
  • CTE / sous‑requêtes pour structurer la logique.
  • Optimisation : index, filtres sélectifs, éviter les full scans.
  • Qualité : contrôle des NULL, cohérence des totaux, détection d’anomalies.

Analyses réalisées

  • Trend analysis : variations MoM/YoY, courbes cumulées.
  • Performance : Top produits, segments, canaux.
  • Part‑à‑tout : contributions par catégorie/canal.
  • Segmentation clients : région, comportement, cohortes.
  • Rapports clients & produits (KPI, parts, anomalies).

Extraits de requêtes

-- Exemple : CA mensuel + MoM/YoY avec fenêtre
WITH monthly AS (
  SELECT DATE_TRUNC('month', o.order_date) AS month,
         SUM(oi.quantity * oi.unit_price) AS revenue
  FROM orders o
  JOIN order_items oi ON oi.order_id = o.id
  GROUP BY 1
)
SELECT month,
       revenue,
       revenue - LAG(revenue) OVER (ORDER BY month)        AS mom_diff,
       100.0 * (revenue / NULLIF(LAG(revenue) OVER (ORDER BY month),0) - 1) AS mom_pct,
       revenue - LAG(revenue, 12) OVER (ORDER BY month)    AS yoy_diff,
       100.0 * (revenue / NULLIF(LAG(revenue,12) OVER (ORDER BY month),0) - 1) AS yoy_pct
FROM monthly
ORDER BY month;
